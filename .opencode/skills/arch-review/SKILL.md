# Architecture Review Skill

## 検出対象
1. 関心事の分離の違反
   - ビジネスロジックとデータアクセスの混在
   - プレゼンテーションロジックの分離不足

2. エラーハンドリング
   - 例外処理の不足
   - エラーレスポンスの不備
   - リソースリーク

3. 設計原則の違反
   - SOLID原則の違反
   - DRY原則の違反
   - 単一責任原則の違反

4. セキュリティ設計
   - 設定のハードコーディング
   - デバッグモードの有効化
   - ホスト設定の問題

## 分析手順
1. モジュール構造を分析
2. 依存関係を追跡
3. 責務の分離を評価
4. エラーハンドリングパターンを確認
5. 設計パターンの適用状況を評価
6. 改善提案を生成
